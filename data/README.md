# Inputs

Chapters 1-2 use `credit-scoring/`; Chapter 4 uses `credit-spreads/`; Chapter 6
uses `climate/`. Foundations and Chapters 3/5 specify their inputs in code.

The chapter readmes and data dictionaries document units and provenance.
Available frozen inputs are retained for numerical reproduction. The
complete credit-scoring dataset is included in the private repository.
Its [provenance note](credit-scoring/PROVENANCE.md) describes the source,
modifications and pending public-release review. Do not replace reference inputs
with current observations when checking the reference edition. Raw climate
data are cleaned inside Chapter 6. Code licensing does not grant rights over
third-party data. Consult the source-specific notes and terms.
